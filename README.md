# Retail Sales Analysis

## Project Overview
This project analyses retail sales data using SQL and Google Sheets to understand sales performance across products, categories, cities and months.

The project contains 300 sales records covering January to August 2026.

## Tools Used
- MySQL – Data querying and analysis
- Google Sheets – Data analysis, pivot tables and dashboard creation
- GitHub – Project storage and documentation

## Dataset
The dataset contains the following columns:
- Sale ID
- Sale Date
- Product Name
- Category
- Quantity
- Price
- City

## Analysis Performed
- Total revenue and average transaction value
- Revenue by product and category
- Revenue by city
- Number of transactions by city
- Average revenue by city
- Monthly revenue trends
- Product quantity analysis

## Key Findings
- Total revenue: ₹1,98,11,400
- Total transactions: 300
- Average revenue per transaction: ₹66,038
- Highest single sale: ₹4,00,000
- Laptop was the highest revenue-generating product.
- Chennai generated the highest revenue among the four cities.
- March recorded the highest monthly revenue.

## Project Files
